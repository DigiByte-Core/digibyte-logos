# DigiDollar Green Colour Variant

Optional green-and-white community variant of the DigiDollar logo. This set uses exactly the same geometry, spacing, lettering, rings, and rounded monogram as the primary blue artwork; only the palette changes.

This optional set does not replace the primary blue DigiDollar assets.

## Colours

- Dark green: `#113A29`
- Light green: `#16804F`
- White: `#FFFFFF`

## Which file to use

- CoinGecko: `Bitmap/Full Badge/DigiDollar-full-badge-green-200x200.png`
- Exchanges and listings: use a full-badge PNG at 256 px or above, or `Vector/DigiDollar-full-badge-green.svg`
- Compact UI and small icons: use `Vector/DigiDollar-badge-glyph-green.svg` or a matching file in `Bitmap/Badge Glyph/`
- SVG favicon: `Icons/favicon-green.svg`
- ICO favicon: `Icons/favicon-green.ico` (exact 16, 32, and 48 px layers)
- Apple touch icon: `Icons/apple-touch-icon-green.png` (180 x 180, opaque RGB)
- Android/PWA icons: `Icons/android-chrome-green-192x192.png` and `Icons/android-chrome-green-512x512.png` (opaque RGB)

Rename a selected green icon to its platform's standard deployment filename, for example `favicon.ico`, `apple-touch-icon.png`, or `android-chrome-192x192.png`.

All full-badge and badge-glyph PNGs preserve transparency outside the circular mark. Apple and Android/PWA icons use an opaque dark-green background and contain no alpha channel. The 16 px glyph still reads as a dark-green coin with a white monogram.

## Vector construction

The SVG artwork contains only flat, closed, filled vector paths. It has no live text, fonts, embedded bitmaps, strokes, transforms, gradients, filters, masks, or external references. Lettering is stored as precision vector outlines, and the rounded monogram is one clean closed contour.

The full-badge letterforms were derived from Poppins ExtraBold, released under the SIL Open Font License 1.1. The font file is not included or embedded.
