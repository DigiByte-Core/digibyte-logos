# DigiDollar Logos

Production-ready DigiDollar logo assets for cryptocurrency listings, exchanges, wallets, websites, favicons, and applications.

The primary blue-and-white artwork and the optional green-and-white community variant use identical vector geometry and the same rounded-corner DigiDollar monogram.

## Primary blue palette

- Navy: `#002A7F`
- Sky blue: `#78B8EF`
- White: `#FFFFFF`

## Optional green palette

- Dark green: `#113A29`
- Light green: `#16804F`
- White: `#FFFFFF`

The complete optional green set is in `Colour Variants/Green/`. It does not replace the primary blue set.

## Which file to use

- CoinGecko: `Bitmap/Full Badge/DigiDollar-full-badge-200x200.png`
- Exchanges and listings: use the full badge at 256 px or above, selecting the nearest PNG size or the SVG master
- Full-badge vector master: `Vector/DigiDollar-full-badge.svg`
- Compact UI and small icons: use `Vector/DigiDollar-badge-glyph.svg` or a matching file in `Bitmap/Badge Glyph/`
- Website SVG favicon: `Icons/favicon.svg`
- Legacy browser favicon: `Icons/favicon.ico` (exact 16, 32, and 48 px layers)
- Apple touch icon: `Icons/apple-touch-icon.png` (180 x 180, opaque RGB)
- Android/PWA icons: `Icons/android-chrome-192x192.png` and `Icons/android-chrome-512x512.png` (opaque RGB)

The full badge is intended for 256 px and above, where the circular lettering remains readable. The text-free badge glyph is specifically fitted for compact placements; its 16 px export still reads as a navy coin with a white monogram.

All full-badge and badge-glyph PNGs preserve transparency outside the circular mark. Apple and Android/PWA icons use an opaque navy background and contain no alpha channel.

## Vector construction

The SVG artwork contains only flat, closed, filled vector paths. It has no live text, fonts, embedded bitmaps, strokes, transforms, gradients, filters, masks, or external references. Lettering is stored as precision vector outlines, and the rounded monogram is one clean closed contour.

The full-badge letterforms were derived from Poppins ExtraBold, released under the SIL Open Font License 1.1. The font file is not included or embedded.
